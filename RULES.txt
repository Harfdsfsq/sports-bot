2) Делать то что написанно в запросе
3) Изменять файлы в репозитории или же добавлять новые
4) Делать run workflow
Как должен работать скрипт:
Автозапуски каждые 2 часа
Начало работы в 00:00 по МСК
В 00:00 он должен выгрузить весь список матчей за день
Все данные которые получает за день сохранять
Каждый запуск должен добавлять данные для матчей
В день должно быть от 2 до 7 прогнозов, в идеале 4-5
# Контекст искусственного интеллекта для спортивного бота

## Проект
sports-bot / HARIZON — Telegram-бот для прогнозирования ставок на футбол.

## Основные цели
- 3-5 качественных прогнозов в день.
- Не снижайте качество прогнозов только для увеличения объема.
- Используйте как можно больше полезных API.
- Правильно сопоставляйте все матчи у разных провайдеров.
- Включайте погоду, новости, коэффициенты, xG, травмы, форму команды, движение линий.
- Отправляйте четкие отчеты в Telegram.

## Правила общения
- Отвечайте на русском языке.
- Будьте прямолинейны и практичны.
- Сначала дайте заключение, а затем подробности.
- Для задач с кодом: сначала изучите репозиторий, а затем предлагайте конкретные изменения.
- Избегайте общих советов.
