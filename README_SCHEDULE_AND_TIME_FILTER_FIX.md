Изменения в этом архиве:

1. .github/workflows/run-bot.yml
- расписание изменено на запуск каждый день в 05:00 UTC, что соответствует 08:00 МСК
- добавлена переменная MIN_KICKOFF_LEAD_MINUTES со значением по умолчанию 30

2. app/services/runner.py
- фильтр матчей больше не возвращает весь исходный список, если после отбора ничего не осталось
- теперь публикуются только матчи, которые начинаются не раньше чем через MIN_KICKOFF_LEAD_MINUTES минут
- по умолчанию буфер до матча: 30 минут

Если хочешь изменить буфер, добавь GitHub Variable:
MIN_KICKOFF_LEAD_MINUTES = 30
или другое число в минутах.
