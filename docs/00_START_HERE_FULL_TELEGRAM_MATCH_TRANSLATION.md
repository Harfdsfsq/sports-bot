# Полный перевод матчей в Telegram

## Что это меняет

Раньше перевод был точечным: мы добавляли конкретные пары команд вроде:

```text
Al-Fateh SC — Al-Khaleej Club
```

Теперь добавлен общий Telegram-normalizer:

1. Ищет строки вида:

```text
1. Team A — Team B
```

и переводит обе команды автоматически.

2. Ищет строку:

```text
🏆 Турнир: Country - League
```

и переводит страну/лигу автоматически.

3. Ищет строку ставки и заменяет известные названия команд внутри неё.

4. Если команда неизвестна, используется fallback-транслитерация:
   - `Dubai United FC` → `Дубай Юнайтед`
   - `Al-Khaleej Club` → `Аль-Халидж`
   - `Manchester United` → `Манчестер Юнайтед`
   - `Yantra Gabrovo` → `Янтра Габрово`

5. `app/services/telegram.py` теперь патчится так, чтобы любой Telegram-текст проходил через `normalize_telegram_text()` перед отправкой.

## Что важно

Это не база официальных русских названий всех клубов мира. Это гибрид:

- точный словарь для частых клубов/лиг;
- общий перевод стран и типов турниров;
- безопасная транслитерация для неизвестных команд.

Так бот перестаёт зависеть от ручного добавления каждой новой пары.

1. Распакуй архив в корень репозитория.
2. Проверь diff в GitHub Desktop.
3. Commit + push.
4. Запусти обычный `Run bot` с profile `balanced`.

## Ожидаемый результат

```text
1. Аль-Фатех — Аль-Халидж
🏆 Турнир: Саудовская Аравия - Про-лига
```

Для неизвестных команд будет не английский сырой текст, а русская транслитерация.
