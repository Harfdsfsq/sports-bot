# Какой env брать

## balanced_output.env

Бери этот профиль, если задача — не убить количество ставок, но убрать самые опасные heavy-shrink/high-odds публикации.

Подходит как стартовый hotfix на 3–5 дней наблюдения.

## conservative_passability.env

Бери этот профиль, если сейчас главная цель — уменьшить мусорные публикации, даже ценой падения количества сигналов.

Подходит для фазы стабилизации после серии плохих результатов.
