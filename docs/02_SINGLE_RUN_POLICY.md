# Single-run режим

Workflow запускает внутренний бот в dry-run, чтобы получить один фиксированный snapshot.
После этого внешний strict gate:
- читает результат того же запуска;
- решает, можно ли публиковать;
- при успехе сам отправляет сообщение в Telegram;
- собирает единый bundle с артефактами.

Это сохраняет принцип `один workflow run = один набор данных`.
