Мини-патч на отображение коэффициентов в settlement/daily review.

Что исправлено:
- коэффициент в блоке расчёта завершённых ставок теперь может показываться с 3 знаками,
  если у реальной цены значима третья цифра;
- это убирает визуальное расхождение между показанным odds и P&L на четвертных линиях.

Пример:
- было: @ 2.02 | P&L: +12.30
- стало: @ 2.025 | P&L: +12.30
