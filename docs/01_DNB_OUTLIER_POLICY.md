# DNB outlier policy

## Разрешаем

DNB/Фора 1(0), Фора 2(0) публикуется, если:

- 2+ линии букмекеров;
- положительный canonical EV;
- DNB xG EV положительный;
- xG и модель не расходятся экстремально;
- для proxy + 1 source выполнены усиленные edge/EV/confidence.

## Не публикуем

- proxy + 1 source с абсурдно высоким xG EV;
- DNB no-push probability выше лимита;
- xG edge выше лимита;
- разрыв модели и xG выше лимита.

Задача: не ловить “сказочные” value-сигналы, которые вероятнее являются ошибкой данных.
