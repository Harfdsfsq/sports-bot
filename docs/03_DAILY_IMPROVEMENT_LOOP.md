# Daily improvement loop

1. Run the bot.
2. Build the learning bundle.
3. Look at three things first:
   - top rejection reasons
   - published candidates vs shadow candidates
   - bankroll / open exposure
4. If a suspicious pick appears, compare:
   - published odds
   - consensus probability
   - selected line
   - normalized line
5. Send the bundle for review.
6. Apply one small config or code change at a time.
7. Re-run and compare the next bundle.

This is how you move from guesses to controlled iteration.
