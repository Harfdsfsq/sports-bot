HARIZON SPORTS BOT — API DOCUMENTATION CATALOG
Last checked online: 2026-04-30
Repository: Harfdsfsq/sports-bot

Purpose
-------
Single text index for all external APIs mentioned for the bot. This file is not a replacement for vendor docs; it is a practical connection map: documentation URL, base URL where known, auth style, useful endpoints, bot secret/env names, and implementation notes.

Confidence legend
-----------------
official         = official vendor documentation or official vendor page found.
official/limited = official vendor/product page found, but complete endpoint reference was limited or not indexable.
marketplace      = RapidAPI/marketplace page found; exact endpoint schema must be confirmed in the marketplace console.
unverified       = no stable official docs found from public search; manual console/API check required.

Important project note
----------------------
api-football / API-FOOTBALL is intentionally removed from active runtime in this project. Its documentation is still listed here for reference, but it must not be restored without explicit user request.


1) Currents News API
--------------------
Status: official
Docs: https://www.currentsapi.services/en/docs/
Official libraries: https://www.currentsapi.services/en/docs/official
Main use in bot: news/context enrichment.
Auth: API key. Currents examples commonly use an Authorization header or apiKey depending on endpoint/client.
Common endpoints:
- Latest news
- Search news
- Available languages/countries/categories via docs
Bot env/secrets:
- CURRENTS_API_KEY
- CURRENTS_KEY
Repo budget group: newsapi_currents
Notes:
- Use sparingly; cache football news context.
- Prefer targeted club/team queries, not broad sports queries.

2) GNews API
------------
Status: official
Docs: https://docs.gnews.io/?lang=en
Base URL: https://gnews.io/api/v4
Auth: query parameter `apikey=YOUR_API_KEY`.
Common endpoints:
- /search?q=...
- /top-headlines
Bot env/secrets:
- GNEWS_KEY
Repo provider: gnews
Notes:
- Good for targeted news confirmation.
- Current budget throttles it heavily; do not expect every run.

3) NewsAPI
----------
Status: official
Docs: https://newsapi.org/docs
Auth docs: https://newsapi.org/docs/authentication
Everything endpoint: https://newsapi.org/docs/endpoints/everything
Base URL: https://newsapi.org/v2
Auth:
- query parameter `apiKey=...`, or
- header `X-Api-Key: ...`, or
- header `Authorization: ...`
Common endpoints:
- /v2/everything
- /v2/top-headlines
Bot env/secrets:
- NEWSAPI_KEY
Repo budget group: newsapi_currents
Notes:
- Prefer header auth to avoid leaking key in logs.
- Use for context only; do not let news-only signals create picks.

4) odds-api.io
--------------
Status: official
Docs: https://docs.odds-api.io/
Auth: https://docs.odds-api.io/authentication
Odds guide: https://docs.odds-api.io/guides/fetching-odds
Base URL: https://api.odds-api.io/v3
Auth: query parameter `apiKey=YOUR_API_KEY`.
Useful endpoints:
- GET /v3/sports
- GET /v3/leagues
- GET /v3/events?apiKey=...&sport=football
- GET /v3/odds?apiKey=...&eventId=...&bookmakers=...
- GET /v3/odds/multi?apiKey=...&eventIds=...&bookmakers=...
Bot env/secrets:
- ODDS_API_IO_KEY
- ODDS_API_IO_KEY_2
- ODDS_API_IO_BOOKMAKERS_ACCOUNT1
- ODDS_API_IO_BOOKMAKERS_ACCOUNT2
Repo provider: odds_api_io
Notes:
- This is the current primary bootstrap/odds source.
- Multi-odds endpoint is efficient and should remain the main odds fetch path.
- Account split currently routes Bet365/Unibet and Betfair Exchange/Sbobet separately.
