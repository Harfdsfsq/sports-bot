# Основание для пакета

Пакет собран на основе следующего наблюдения из резюме:

- за последние 2 дня бот несколько раз не выпустил прогнозы из-за guard-фильтров;
- реализованных ставок было 5, из них 2 выиграли;
- главные блокеры — market-derived signal guards и publish/books-related фильтры;
- слабые стороны: агрессивный shrink, жёсткие требования по числу букмекеров, слабая работа с низкотировыми/низкотирными лигами, недостаток фичей и слабая калибровка;
- рекомендуемые направления: смягчение порогов, калибровка вероятностей, расширение признаков, better bankroll and monitoring.

Из этого сделан практический пакет, который даёт:

1. инструментирование;
2. мягкую калибровку;
3. улучшенный экспорт;
4. готовый overlay для `.env`;
5. план rollout на 6 недель.
