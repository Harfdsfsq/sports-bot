# Top frequency policy

## Balanced

- окно: 30 часов;
- до 3 прогнозов за run;
- дополнительные пики требуют EV >= 7%, edge >= 3 п.п., confidence >= 67%;
- общий риск <= 1.8% банка;
- Tier C не публикуется.

## Conservative

- окно: 24 часа;
- до 2 прогнозов за run;
- дополнительные пики требуют EV >= 8.5%, edge >= 3.8 п.п., confidence >= 69%;
- общий риск <= 1.25% банка.

## Почему это должно давать ставки чаще

Раньше из 3 подходящих кандидатов публиковался только один. Теперь бот может публиковать несколько, но только если каждый проходит финальные guard'ы. Это повышает частоту без возврата к слабым single-book/Tier C прогнозам.
