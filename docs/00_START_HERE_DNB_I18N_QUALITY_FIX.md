# DNB sanity + Telegram i18n quality fix

## Что исправляет

Последний прогноз:

```text
SKU Amstetten — First Vienna FC 1894
Фора 0 / DNB — First Vienna FC 1894 (0)
Austria - 2. Liga
```

после патча должен отображаться так:

```text
СКУ Амштеттен — Фёрст Вена 1894
Фора 0 / DNB — Фёрст Вена 1894 (0)
Австрия - Вторая лига
```

## DNB sanity-check

Для DNB добавлена отдельная xG-проверка через poisson:

- `P(win)`
- `P(draw/push)`
- `P(loss)`
- `P(win | не ничья)`

Для твоего примера:

```text
xG: 0.69 : 2.04
DNB First Vienna по xG без ничьей: ~85.7%
модель: 53.7%
```

Это означает, что xG поддерживает направление ставки; модель здесь даже консервативнее xG.

В Telegram появится строка:

```text
🔎 DNB-проверка: без ничьей 85.7% | разрыв -32.0 п.п.
```

## Защиты

- Если модель сильно оптимистичнее DNB-xG, кандидат режется или понижается.
- Отрицательный EV по-прежнему запрещён.
- Proxy-quality не даёт Tier A.
- Время остаётся в формате MSK.
