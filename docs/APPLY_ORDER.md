# Порядок применения

1. Скопируй папки `app`, `scripts`, `config`, `docs` поверх репозитория.
2. Выбери один файл из `config/` и перенеси нужные переменные в свой `.env`.
3. Запусти `scripts/extract_run_summary.py` на свежем zip-логе и проверь, поменялись ли top rejections.
4. Дай профилю 3–5 дней или 20+ settled ставок.
5. Только после этого решай, возвращать ли `market-derived` в боевой pipeline.
