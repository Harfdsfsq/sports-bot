# Information that is especially valuable for future improvements

Keep saving these fields and files because they are the most useful for tuning the bot:

- raw and adjusted probability
- market probability
- selected bookmaker and source
- books count / sources count
- model mode
- publication score
- quality score and quality reasons
- top guard rejections per run
- shadow tracking candidates
- bankroll snapshot per published bet
- daily quality analysis
- next day adjustments
- recent run archives

If these traces are present, it becomes much easier to:
- detect bad odds mapping
- separate profitable market types from noisy ones
- tune historical guard relief safely
- identify which leagues should stay core / shadow / reject
- calibrate confidence and stake size
