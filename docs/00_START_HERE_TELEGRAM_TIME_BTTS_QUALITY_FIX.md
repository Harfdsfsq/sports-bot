# Telegram time + BTTS quality fix

## Что исправляет

Последний прогноз показал две регрессии:

1. Время снова вышло в UTC ISO:

```text
2026-04-24T15:45:00+00:00
```

Теперь снова будет:

```text
24.04.2026 18:45 MSK
```

2. Матч/турнир снова вышли на английском.

Теперь Telegram-текст снова проходит через полный нормализатор:
- `Al-Fateh SC — Al-Khaleej Club` → `Аль-Фатех — Аль-Халидж`;
- `Saudi Arabia - Saudi Pro League` → `Саудовская Аравия - Про-лига`.

3. Для рынка `Обе забьют` добавлена отдельная sanity-проверка по xG.

Для `ОЗ: Нет` считается:

```text
P(ОЗ Да) = (1 - exp(-xG_home)) * (1 - exp(-xG_away))
P(ОЗ Нет) = 1 - P(ОЗ Да)
```

В Telegram появится строка:

```text
🔎 ОЗ-проверка: ориентир ...% | разрыв ... п.п.
```

## Что не меняется

- отрицательный EV запрещён;
- proxy-quality не даёт Tier A;
- старые shadow-кандидаты не используются как источник ставок.

## Как применить

1. Распакуй архив в корень репозитория.
2. Проверь diff в GitHub Desktop.
3. Commit + push.
4. Запусти обычный `Run bot` с profile `balanced`.
