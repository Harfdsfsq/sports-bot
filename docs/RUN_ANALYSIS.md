# Что ломало последние прогоны

По последним логам были видны четыре системные проблемы:

1. `Odds-API.io` почти не давал офферы, потому что матчинг событий был слабым, а odds-запросы шли не по лучшему списку events.
2. `BookiesAPI` матчился лучше, но часть лимита уходила на synthetic/eSoccer события.
3. `API_FOOTBALL_KEY`, `BZZOIRO_API_KEY` и `SHEET_ID` были в secrets, но не использовались пайплайном.
4. Старое поведение с Google Sheets пропало после перехода с Apps Script на Python/GitHub Actions.

Этот пакет правок адресует именно эти четыре пункта.
