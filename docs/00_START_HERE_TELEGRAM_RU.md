# Полный русский текст Telegram-сообщений

Этот patch-pack переводит пользовательские Telegram-сообщения в единый русский стиль.

## Что меняется

- Убираются англоязычные термины из сообщений:
  - `controlled fallback` → `контролируемый резерв`
  - `Tier A/B/C` → `уровень A/B/C`
  - `single-book` → `одна линия букмекера`
  - `single-source` → `один источник`
  - `heavy-shrink` → `сильная корректировка`
  - `non-core` → `вне основного пула`
  - `canonical value` → `контрольная ценность`
  - `quality-layer` → `слой качества`
- Основной TelegramPublisher нормализует текст перед отправкой.
- Controlled fallback publisher тоже нормализует текст перед отправкой.
- Workflow `Run bot` применяет патч перед запуском бота.

## Как применить

1. Распаковать архив в корень репозитория.
2. Проверить diff в GitHub Desktop.
3. Commit + push.
4. Запустить обычный workflow **Run bot**.

## Важно

Патч не меняет расчёт ставок, EV, вероятностей и фильтров. Он меняет только пользовательский текст Telegram-сообщений.
