# Final accuracy rules

## Публикуем

- Tier A/B.
- 2+ bookmaker lines.
- Tier C не публикуется.
- Single-book proxy не публикуется.
- Proxy + 1 source допускается только при усиленном EV/edge/confidence.
- DNB требует xG fair-odds подтверждение.
- Тоталы требуют xG sanity.
- ОЗ требует BTTS xG sanity.

## Не публикуем

- отрицательный EV;
- матч вне окна;
- дубль;
- proxy без рыночного подтверждения;
- DNB без xG EV;
- слабый edge при одном источнике;
- Tier C.
